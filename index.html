Koneksi YouTube

memeriksa…

1 · Siapkan Google Cloud (sekali saja)

  1. Buat project baru, misalnya “Pabrik Pixel”.
  2. Aktifkan YouTube Data API v3 (tombol Enable).
  3. Google Auth Platform → Get started: isi nama aplikasi & emailmu, pilih External.
  4. Audience → Publish app (status In production). Kalau dibiarkan “Testing”, koneksi putus tiap 7 hari.
  5. Buat OAuth client: tipe Web application, lalu di Authorized redirect URIs tambahkan alamat ini persis:
  6. Salin Client ID dan Client secret yang muncul ke kolom di bawah.

2 · Hubungkan

Kunci dikirim terenkripsi langsung ke GitHub Secrets repo pabrik-pixel dan tidak disimpan di HP ini. Token GitHub di Pengaturan perlu izin tambahan Secrets: Read and write. Saat Google menampilkan “Google hasn’t verified this app”, ketuk Advanced → Go to … (unsafe) — itu aplikasimu sendiri.

3 · Uji dari pabrik

Menjalankan pengecekan di GitHub dengan kunci yang tersimpan (±1 menit), hasilnya muncul di kotak status di atas.

4 · Audit API (agar video tidak terkunci private)

Video yang diupload lewat API dari project yang belum diaudit Google akan terkunci private. Ajukan sekali lewat formulir audit YouTube API (gratis, beberapa minggu). Sambil menunggu, pilih “Draf private” saat menyetujui video lalu jadwalkan di YouTube Studio.
