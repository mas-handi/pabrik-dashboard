Kebijakan Privasi — Pabrik Pixel

Pabrik Pixel adalah alat pribadi milik pemilik kanal untuk membuat dan mengunggah video animasi ke kanal YouTube miliknya sendiri. Aplikasi ini tidak dipakai oleh orang lain.

Data yang diakses

Dengan izin pemilik akun, aplikasi memakai YouTube Data API untuk: mengunggah video dan thumbnail ke kanal pemilik, menjadwalkan tayang, serta membaca nama kanal dan jumlah penayangan video yang diunggah aplikasi ini.

Penyimpanan

Token akses disimpan terenkripsi di GitHub Secrets repositori privat milik pemilik kanal. Tidak ada data yang dijual, dibagikan, atau dipakai untuk iklan. Data YouTube hanya dipakai untuk menampilkan status video di dashboard pribadi.

Mencabut akses

Akses dapat dicabut kapan saja di myaccount.google.com/permissions. Penggunaan data YouTube tunduk pada Persyaratan Layanan YouTube dan Kebijakan Privasi Google.
